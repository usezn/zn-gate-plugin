# Security

Please report vulnerabilities in zn-gate or in this plugin to security@usezn.com, or privately through GitHub security advisories in [usezn/zn](https://github.com/usezn/zn/security/advisories/new). The security policy, supported versions and response times are in the [usezn/zn security policy](https://github.com/usezn/zn/security/policy).
